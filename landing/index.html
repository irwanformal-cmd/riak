Mathematical reasoning

Every ripple can show its work.

Predictions ship with a step-by-step derivation — sign chains for qualitative reasoning, quantitative mechanisms when the scenario is numeric.

derivation · fare → ridership → congestion
  1. 1 · fare elasticity
    ΔQQ = εd · ΔPP, εd ≈ −0.42  (urban transit)
  2. 2 · fare goes to zero
    ΔPP = −1 ⇒ ΔQQ ≈ +0.42 ridership rises ≈ 42%
  3. 3 · mode shift off the roads
    ΔVcar = −σ · ΔQtransit, σ ≈ 0.31 transfer coefficient ⇒ Vcar −13%
  4. 4 · congestion response
    C = Vκ · Rcap ⇒ C′ ≈ C · (1 − 0.13)1.6 ≈ 0.80 C
  5. 5 · propagation into the web
    s(n) = ∏e ∈ path we · s(root) max-times chain · P10–P90 via Monte-Carlo
